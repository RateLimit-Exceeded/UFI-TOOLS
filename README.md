## 简介  
  自用修改版，不会与原始仓库同步  
  

## 特性

- 移除了云端设备限制、信息收集与上报
- 移除了原始开发者面向用户的信息推送、软件OTA等远程代码执行能力
- 支持自定义插件商店，更多私有化插件源以及插件仓库密码配置，使用[openlist](https://github.com/OpenListTeam/OpenList)搭建


## 下载与使用
 请前往[github action](https://github.com/XuF163/UFI-TOOLS/actions)获取最新编译的apk
